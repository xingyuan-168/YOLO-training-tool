# Requirements

## 目标

YOLO-V1：个人使用的 Windows 10 22H2 / Windows 11 x64 本地工作台，中文界面，完成图片采集、矩形标注、数据检查、训练、评估、部署验证、导出和问题样本回流。依据用户 2026-10-04 实施方案和 input/UI-1..4.png。

## 需求

| ID | 首版要求 |
|---|---|
| DATA | 新建/打开/最近项目，图片目录和 YOLO 目录/ZIP 导入，来源只读；区分未标注/已标注/确认无目标；缩略图虚拟列表；回收区 |
| LABEL | 矩形创建、选择、移动、缩放、复制、删除、类别切换、缩放平移、撤销重做、原子自动保存、导航、负样本确认 |
| CLASS | 类别新增/重命名/受控删除/重排，预览迁移及恢复；历史模型保留训练类别映射 |
| CHECK | 损坏图、缺失/孤立/非法标签、重复图框、类别分布、异常尺寸、数据泄漏；按会话分组划分，默认 80/20 seed=42 |
| SNAPSHOT | 每次训练冻结图片、标签、类别、划分、参数；图片硬链接或复制，工作标签变化不影响历史快照 |
| CAPTURE | 桌面/窗口枚举与选窗、客户区预览、单张/5秒定时/Ctrl+E、DPI、来源元数据、有界队列、关闭/最小化/无新帧状态 |
| TRAIN | v8/11/26 n/s/m/l/x，CPU/CUDA 单训练；基础/高级/专家 YAML，参数预检；损失/指标/资源/日志；安全停止/强停/完整恢复/基于权重继续区分 |
| EVAL | Ultralytics 标准指标和部署结果来源分离；图片/目录/视频/窗口输入；CQ_AI、NCNN、通用模型按能力启用阈值；错误样本回流 |
| EXPORT | PT/ONNX/NCNN 通用包、AScript v8 包、CQ_AI 包；结构检查和隔离加载通过后才标成功；重复导出不覆盖 |
| PERF | 同模型、尺寸、后端、精度、设备，预热后 P50/P95、吞吐量及端到端耗时；30分钟稳定性 |
| UI | 四主入口：标注训练/验证/日志/设置；1366×768 至 1920×1080，DPI、键盘、可调整分栏、明确错误与状态 |
| PACKAGE | GUI/训练/推理环境隔离；CPU 便携基础包、可选 NVIDIA；首次准备后离线；不在任务中静默安装 |

新项目默认 v8n / 640 / 100 epochs；CPU batch=4 workers=0，CUDA 自动 batch workers=4；confidence=0.5，CQ_AI IoU=0.45 只读，FP32 单会话。导入配置以原配置经校验后的值为准。

## 验收标准

见 TEST_PLAN.md。缺少 NVIDIA 硬件、AScript 使用端或真实业务数据时，相应项必须记为待验，不能用 CPU 或零输入结果替代。前端需具体 HTML 原型和 UI 规范获得用户批准后开始实现。
