# UI Spec

## 布局

原型版本 01，范围 YOLO-V1。批准状态：待用户查看当前 PROTOTYPE.html 后明确批准；“实施方案”不代替具体原型批准。原型只用内嵌演示数据，没有运行训练、安装依赖或改写项目。

窗口基准 1366×768，另检查 1920×1080。生产端为 PySide6 Widgets，不把 HTML 嵌入生产主界面。顶栏四个主入口：标注训练、验证、日志、设置。保留 input/UI-1..4.png 的信息架构，改善间距、状态和可调整布局。

标注训练：顶部项目/导入/截图/检查工具栏；左侧 220–255 px 图片列表；中间弹性深色标注画布；右侧 300–340 px 类别和参数；底部可展开监控。生产端用 QSplitter 保存分栏宽度，右栏内容可滚动，类别区可折叠。原型使用响应式 Grid 演示默认宽度，尚未实现拖动分隔条。

验证：现场识别、数据集评估、模型导出、性能测试四个子页。现场识别采用左侧配置、右侧画面和结果表。模型导出按“通用 / AScript v8 / CQ_AI”三类契约选择。

日志：单一可搜索日志区，任务/级别过滤，自动滚动开关、复制和导出。

设置：运行环境、设备与模型、截图与快捷键、目录与恢复四组。

## 组件

| 项目 | 规格 |
|---|---|
| 字体 | Segoe UI / Microsoft YaHei UI；正文 13 px，辅助 11–12 px，标题 17–18 px |
| 背景/文本 | 浅灰 #f3f5f8，正文 #172238，画布 #18212f，主操作 #2563eb |
| 控件 | 默认圆角 6 px，面板 9 px，面板间距 12–16 px，主操作避免图标单独表达 |
| 状态 | 图形 + 文字；就绪/已保存绿、运行中蓝、待处理黄、失败红；不只依赖颜色 |
| 焦点 | 键盘焦点描边清晰；Tab 顺序按视觉顺序；文本输入时不触发绘框/导航快捷键 |
| 长内容 | 路径省略并可查看完整值；列表滚动；错误正文换行；日志可横向查看完整行 |

画布：W 绘框、V 选择；选中框可拖动移动、右下角缩放；滚轮缩放、适应画布；Ctrl+Z / Ctrl+Y；Ctrl+C 复制选中框；Del 删除；A/D 或左右键导航；1–6 选择类别。原型可演示以上操作。生产端增加空格拖动平移、多手柄缩放、下一张未审核、手动保存和自定义快捷键。

数据状态严格区分：未标注、已标注、已确认无目标。删除最后一个框不能自动视作已审核负样本。“确认无目标”明确提示清空标注，可撤销。切换图片前完成当前原子保存；失败时阻止静默丢失并允许重试。

类别管理：重命名不改变 ID；删除/重排先预览映射和受影响图片，再应用可恢复迁移。训练模型类别来自其快照。原型演示重命名、重排预览和确认，当前示例类别顺序不实际迁移。

训练：基础/高级/专家三级参数。确认面板列出数据/环境检查和生效参数；明确排除未审核数据，不自动算负样本。正式端须显示所有最终生效参数，可展开完整 YAML。专家配置禁止覆盖数据、输出、resume、任务协议。

CQ_AI IoU 显示 0.45 且只读；有 NMS 的 NCNN/PT 可调；YOLO26 通用端到端模型禁用不适用 IoU。实际设备和耗时随 Worker 返回，不根据 AUTO 名称猜测。

## 状态与反馈

| 场景 | 入口 | 可见反馈与恢复 |
|---|---|---|
| 空项目 | 顶部“查看流程 / 空项目”或新建 | 导入/截图入口，无假数据计数 |
| 导入 | 导入数据 / 流程选择 | 类型、保留源文件、重复检查、未标注统计；确认后示例列表出现 |
| 标注 | 默认工作区 | 选中框、类别、框数、保存状态；撤销/重做 |
| 数据问题 | 数据检查 | 可阻断错误与提醒分开，未审核样本不作负样本，可返回筛选 |
| 划分 | 左侧“划分” | 80/20、seed=42、采集会话策略、明确排除未审核数据 |
| 训练中 | 开始训练确认 / 流程 | Epoch、指标、损失、设备与日志；标注仍可用；第二次启动被阻止 |
| 安全停止 | 停止并保存 | 等待安全保存点 → 已停止，显示完整恢复检查点 |
| 强制结束 | 停止对话框 | 提示当前 Epoch 未保存部分丢失，仅终止本工具进程 |
| 失败 | 流程 / 训练失败 | 保留最后完整检查点、日志任务关联、可恢复入口 |
| 恢复 | 已停止 / 恢复确认 | 原数据快照、优化器/调度器/进度；样板 last.pt 只能作为权重续训 |
| 采集失效 | 窗口已关闭 | 停止保存无效图，重选来源；正式端也覆盖最小化、权限和无新帧 |
| 不兼容模型 | 流程 / 模型不兼容 | 禁止启动不兼容后端；提示选择通用后端；不靠改后缀解决 |
| 导出 | 验证 / 模型导出 | 新目录、转换→结构→隔离加载→完成；包内容预览 |
| 导出失败 | 流程 / 导出失败 | 保留原模型，失败产物不进可用列表，可查看原因并重试 |
| 问题回流 | 现场识别 / 保存问题样本 | 原图 + 模型与阈值 + 备注；进入待标注，不自动把预测变真值 |
| 环境问题 | 设置 / 运行诊断 | 显示版本/路径/硬件状态和修复建议；缺 NVIDIA 为待验，不误报已通过 |

原型的训练/评估/识别/导出和性能值是演示，顶部固定标识。原型只允许“导出日志”生成演示日志文件。生产界面不显示内部协议和开发术语，除非用户打开诊断或专家配置。

生产端验收：常用 DPI 下无关键操作裁切、键盘可达、长路径可读；任务错误有重试/恢复入口；训练/采集/推理均不中断主界面。原型评审通过不等于生产功能或硬件验收通过。
