# Test Plan

## 测试范围

每个阶段记录真实命令和结果。单元测试覆盖文件一致性与协议；集成测试运行真实 CPU 推理和小数据集训练；UI 视觉检查覆盖 1366×768/1920×1080 与关键异常状态。

## 验收矩阵

| 范围 | 本批结果 | 后续验收 |
|---|---|---|
| 标签/数据 | 非法坐标、像素往返、中文空格路径、重复源、状态、锁、回收、索引重建 | ZIP、批量导入、万图浏览 |
| 一致性 | 写入故障回滚、子进程中断恢复、类别迁移/受控撤回、快照隔离 | 磁盘满、权限、外部篡改恢复 UI |
| 训练参数 | 默认值、CPU Batch、专家白名单、非法值 | 全部 Ultralytics 参数约束与 UI 联动 |
| 模型契约 | CQ 与 AScript 布局；错误类别/尺寸/精度/系列/opset 拒绝 | 生产导出管线和跨格式 FP32 数值门槛 |
| 真实运行 | CQ CPU 适配与直接调用相同；两套 NCNN 零输入；v8/11/26n ONNX 执行；v8n CPU 实训 | 其他规模实训、停止/完整恢复任务、NCNN 官方转换、真实使用端 |
| 原型 | 四页导航、删除/撤销、停止确认、不兼容禁用、导出失败、日志筛选、设置诊断；两尺寸 | 用户批准、PySide6 实现、DPI、键盘/画布完整操作 |
| 硬件/稳定性 | CPU 基线 | 实际 DirectML、CUDA、TensorRT、AScript Android、30 分钟、干净机器打包 |

执行 `uv run --locked pytest -q` 测轻量服务；`python scripts/smoke_compat.py` 在独立进程执行已准备环境的模型基线。准备与 smoke 的说明见 README。所有业务准确率仍需真实人工验证集。

M0 使用 Nano 架构随机初始化验证三代框架/转换，不代表预训练权重缓存已全部准备，也不代表 n/s/m/l/x 全矩阵已经验收。
