轻量测试：`uv run --locked pytest -q`。GUI测试使用准备好的 GUI Python；真实模型测试通过推理 Python 独立执行。训练集成用 `YOLO_RUN_TRAINING_INTEGRATION=1` 和 `YOLO_TRAIN_PYTHON` 显式启用。性能/长稳工具为 `scripts/soak_inference.py`；便携闭环为 `scripts/smoke_portable.py`。

数值门槛：匹配框类别相同、IoU≥0.99、置信度差≤0.001，固定相同预处理与后处理。不同部署算法分别报告。业务 mAP 必须来自用户人工标注集，合成演示和零输入不替代业务准确率。

缺少设备时明确待验：NVIDIA CUDA/TensorRT、AScript Android、实际多屏/不同DPI/受保护窗口、Windows10及全新机器。仅本机便携迁移与受限联网测试不能冒充全新操作系统验收。n/s/m/l/x可选择；真实兼容回归集中在n规格，其余规模未宣称完成全矩阵训练。
