# Scope

## 范围内

首版：本地个人矩形目标检测、单训练任务、PySide6 桌面、Ultralytics 训练/评估/导出、CQ_AI 0.14.6、AScript v8 独立 NCNN、项目/快照/任务/诊断。输入只读，交付独立环境与便携包。

M0 工程与兼容基线 → M1 四页交互原型与批准 → M2 数据/标注 → M3 采集/推理 → M4 训练/评估 → M5 导出/使用端 → M6 打包/验收。

## 范围外

首版不承诺最小化窗口持续采集、不支持分割/姿态/旋转框，不承诺任意数据固定准确率或未经测量的 FPS。

V2：自动预标注、增强预览、可视化数据版本、实验比较、Datumaro、Optuna、困难样本分析。
V3：远程训练、多 GPU、队列、团队协作。

YOLO26 可训练/通用导出，不宣称兼容现有 CQ_AI 和 AScript v8 解码器。TensorRT 执行和 CUDA 训练由 NVIDIA 设备独立验收。
